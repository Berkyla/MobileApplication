# Arcane Frontier

**Arcane Frontier** — консольная RPG-игра для Android.  
Игра выполнена в фэнтезийном стиле и ориентирована на пошаговый геймплей, исследование этажей и тактический бой.

---

## Описание игры

Игрок исследует этажи подземелья, состоящие из комнат, сражается с монстрами, находит предметы, использует магию и побеждает боссов.  
Цель игры — пройти **3 этажа**, найти ключи, победить всех боссов и дойти до финала.

Управление реализовано **исключительно через кнопки**, по принципу Telegram-ботов, без текстового ввода команд.

---

## Основные возможности

### Мир и исследование
- 3 полноценных этажа
- комнаты, стены, стартовая и босс-комнаты
- миникарта с отображением посещённых комнат

### Пошаговая боевая система
- бой по очереди: игрок → враг
- обычные мобы и уникальные боссы
- физические атаки и магия

### Магия и мана
- отдельное меню **«Магия»**
- заклинания с затратой маны
- магия доступна с начала игры

### Инвентарь и предметы
- оружие и броня
- зелья маны и свитки лечения
- контейнеры: сундуки и мешки
- экипировка влияет на характеристики игрока

### Прогрессия
- для каждого этажа требуется свой ключ
- без ключа босс-комната недоступна

### Сохранение прогресса
- автоматическое сохранение
- возможность продолжить игру
- главное меню с кнопками **«Новая игра»** и **«Продолжить»**

### Финал
- экран победы после прохождения всех этажей

## Управление

Все действия выполняются через кнопки интерфейса:

- **Помощь** — инструкция и сюжетный лор
- **Осмотреться** — описание текущей комнаты
- **Идти** — перемещение (контекстное меню направлений)
- **Атака** — физическая атака
- **Магия** — выбор заклинаний
- **Открыть** — взаимодействие с контейнерами
- **Инвентарь** — предметы и экипировка
